JobFinder Combined V6

START:
1. Extract the ZIP.
2. Keep all HTML files in the same folder.
3. Open login.html.
4. Enter login details.
5. Successful login redirects automatically to home.html.
6. The home page displays the logged-in user's name, email, mobile number and preferred work type.

Demo:
Super Admin: admin@jobfinder.local / Admin@123
Job Seeker: user@jobfinder.local / User@123

Registration:
New job seekers can register on the Login page. Their prototype account is stored in browser localStorage and is then available for login.

Files:
- login.html
- home.html
- user.html
- admin.html
- README.txt

This is a front-end prototype. Authentication/password storage is not production-secure.
